# SEO and Performance Guide

Key points:

- Canonical URL for each page.
- Open Graph and Twitter tags.
- JSON-LD structured data.
- `sitemap.xml`, `robots.txt`, `rss.xml`.
- Lightweight CSS and static hosting.
